2. AppLauncher

My app launcher is something I made because I wanted to contain my massive library of applications

It has a ton of features like
1. Launching games from Steam, Epic, Ubisoft, Microsoft Store, etc..., or standalone .exe files.
2. Automatically fetches a game banner when a game is added via drag and drop from Steam Grid DB.
3. Simple drag and drop to add a game.
4. The ability to add and launch web links in the default browser.
5. The ability to add folders and use them as shortcuts.
6. Shell-mode launching for apps needing separate terminals (like emulators).
7. Adding microsoft store/xbox games to the app and launching them from it.
8. Remotely launch apps from other devices on your local network.
9. Controller navigation.
The app is open source at This repo And has much more features coming to it in the future
You can download AppLauncher to any windows device
