Replay

A FOSS no-nonsense music hub that organizes your library neatly and keeps playback smooth.

Features

1. Dark, minimal interface with album navigation
2. Support for popular audio formats (MP3, M4A, OGG, WAV, FLAC)
3. Song Lyrics (when available)
4. Playback controls: play, pause, skip, shuffle, repeat, speed adjustment
5. Library management
6. Control server for managing playback remotely
7. Built in music downloader
8. Built in Lyrics searcher
